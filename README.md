# Hi, I'm a Machine Learning Engineer

I'm an engineer with a background in Technical Physics, interested in machine learning, time series forecasting, and data-driven problem solving. My work combines practical ML applications with data engineering, statistical analysis, and scientific computing.

I have hands-on experience applying time series forecasting models to real-world demand data, working with AWS SageMaker and Snowflake, and building data pipelines. I've also worked on PM10 air pollution forecasting using LSTM neural networks as part of my thesis.

I'm particularly interested in understanding how models work, evaluating their performance, and building reliable solutions for real-world problems.

## Areas of Interest

- **Time Series Forecasting:** Foundation models, LSTM networks, gradient boosting, forecasting evaluation, and model comparison.
- **Machine Learning:** Classification, regression, feature engineering, data preprocessing, and hyperparameter optimization.
- **Data Engineering & MLOps:** ETL pipelines, data quality, batch inference, and ML pipeline development.
